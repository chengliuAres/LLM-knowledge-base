🔌 MCP 接入

MCP (Model Context Protocol) 是 AI 助手与外部工具之间的开放标准协议。连接后，Claude Code、Cursor 等 AI 工具可以直接搜索代码、追踪调用链、进行 RAG 问答。

📡 服务连接信息

服务地址 —
MCP 端点 /mcp
传输协议 Streamable HTTP
SDK 版本 mcp SDK v1.x
旧端点 (兼容) /mcp/sse

🛠️ 可用工具（5个）

code_search — 混合搜索代码，支持中文查询
code_chat — RAG 代码问答
code_trace — 调用链追踪 (callers/callees)
code_file_context — 获取文件内容
code_list_repos — 列出已索引仓库

Claude Code (CLI)

claude mcp add code-kb 加载中…/mcp

Cursor IDE

{ "mcpServers": { "code-kb": { "url": "加载中…/mcp" } } }

Claude Desktop

{ "mcpServers": { "code-kb": { "command": "npx", "args": [ "-y", "@anthropic-ai/mcp-client", "加载中…/mcp" ] } } }

VS Code / Cline

{ "mcpServers": { "code-kb": { "url": "加载中…/mcp", "transport": "streamable-http" } } }
🔍 搜索代码
"搜索邮件发送相关的代码"
→ code_search(query="邮件发送", repo="mailflutter")
→ 返回 SendMailPage, MailService 等结果
💬 代码问答
"这段邮件发送逻辑是怎么工作的？"
→ code_chat(question="...", repo="mailflutter")
→ RAG 检索 → LLM 解释，返回来源引用
🔗 调用链追踪
"谁调用了 sendMail？它又调用了谁？"
→ code_trace(symbol="sendMail", direction="both")
→ BFS 多跳，返回调用图 + 被调用图
📄 浏览文件
"帮我看下 MailService.dart 的代码"
→ code_file_context(repo="mailflutter", file_path="...")
→ 返回文件完整内容
